# GitHub Repo Polisher Skill
При подготовке репозитория к публикации на GitHub выполни следующие шаги:
1. Проверь и оформи качественный README.md (краткое описание, стек технологий, скриншоты/демо, инструкция по локальному запуску и перечень переменных окружения).
2. Проверь файл .gitignore — убедись, что секреты, `.env`, лог-файлы и тяжелые папки (`node_modules`, `venv`, `.next` и т.д.) исключены из отслеживания Git.
3. Проверь чистоту структуры проекта, удали временные файлы и убедись, что код прокомментирован на ключевых участках.
