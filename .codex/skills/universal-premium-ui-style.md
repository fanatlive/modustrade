# Universal Premium UI Style Skill
При создании и верстке UI-компонентов руководствуйся правилами современного премиального дизайна:
- Используй минималистичный дизайн, чистую типографику и гармоничную цветовую палитру (акцент на контраст и визуальный воздух).
- Применяй аккуратные микро-взаимодействия, скругления (border-radius), мягкие тени и продуманные отступы (padding/margin).
- Избегай перегруженных интерфейсов и устаревших стилей. Делай UI готовым к продакшену и эстетичным.
