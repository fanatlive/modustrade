# Codex Task Executor Skill
При выполнении любых задач в проекте действуй строго по этапам:
1. Исследование: Проанализируй существующую структуру проекта, найди целевые файлы и изучи их контекст перед внесением изменений.
2. Планирование: Опиши точечный план изменений и укажи, какие конкретно файлы будут затронуты.
3. Точечное исполнение: Не переписывай файлы полностью без необходимости. Вноси только минимальные и безопасные правки.
4. Проверка: Убедись, что существующая логика и зависимости не сломаны.
